# Beta Sender Plus

Beta Sender Plus by Beta Sender.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/68f8877cc94350869e2b9462/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Beta Sender Plus** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/68f8877cc94350869e2b9462/releases/latest) and reinstall.
